## 등록 방법 (운영진용)

### 옵션 A — 수동 등록 (참가자 수 적을 때)
1. 각 참가자 계정으로 로그인
2. Calendar → 새 일정 → 위 표대로 입력
3. 참석자 이메일은 워크샵용 더미 이메일 (예: `dow-director@example.com`) 사용

### 옵션 B — Apps Script 일괄 등록 (권장, 30명+ 참가자)
운영진이 Google Apps Script로 위 6개 일정을 모든 참가자 캘린더에 자동 등록. 별도 스크립트 문의.

## 워크샵 진행 흐름과의 연결

이 사전 등록 미팅은 핸즈온 **에이전트 #3 "미팅 사전 브리핑"** 시나리오의 입력 데이터입니다.

참가자가 에이전트에 *"다음주 예정된 미팅 사전 브리프 만들고, Drive에 회사별로 저장해줘"* 라고 요청하면:
1. **Calendar 호출** → 위 6개 케미컬 미팅 자동 인식
2. **각 회사 식별** — Dow Inc. / DuPont / LG화학 / BASF Korea / 롯데케미칼 / 금호석유화학
3. **기업 공시(Custom MCP / SEC EDGAR 등) 호출** — 상장사는 풀 분석, 비상장/외국계 법인은 폴백 메시지
4. **사내 매뉴얼 적용** (데이터스토어) — 화학 미팅 사전 체크리스트
5. **Drive 저장** — `미팅 브리프 [날짜]` 폴더에 회사별 1쪽 마크다운 문서 생성
